# Évaluations

Ce dossier contient les évaluations du cours _"Prise de parole en public
(PPeP)"_.

L'évaluation se compose de deux parties de poids égal :

- l'[auto-évaluation](./01-auto-evaluation/README.md), pour 50 % de la note
  finale ;
- la [présentation finale](./02-presentation-finale/README.md), pour 50 % de la
  note finale.
